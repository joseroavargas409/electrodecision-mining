# Record the actual demo

1. Use the English `/demo` route in your own browser. Reset the default case.
2. Follow `VIDEO_SCRIPT_EN.md`. Capture application operation, including a real model query and executed tools. Preserve the explicit synthetic-data labels.
3. Use a window-only screen capture so unrelated windows, account details and configuration files are not included. Do not show `.dev.vars` or any API key.
4. Read `NARRATION_EN.txt`, or record your narration separately. `CAPTIONS_EN.srt` is a timed draft for a 2:40 cut; align it to the actual edited footage.
5. Keep the final video below three minutes. Use no third-party music or footage without permission. Upload publicly to YouTube and verify the public link.

Automated browser access to localhost was denied in the authoring environment. No recording is claimed here. Use a normal user recording or enable the supported browser access before asking for automated recording. This guide does not provide a bypass.
